# Verification and launch boundaries

## Verified in the implementation environment

- Strict TypeScript, ESLint with zero warnings, pure investment calculation tests and optimized Next.js production build.
- 37 marketing/admin/error routes × 1440/390 viewport widths = 74 automated states: zero serious/critical axe findings, horizontal document overflow, broken images or browser page errors. Page title and description length gates passed. Custom 404 correctly returns HTTP 404.
- The audit also exercises mobile navigation, gallery empty-state recovery and native lightbox Escape handling.
- Real browser physical-click enquiry flow, validation and consent errors, demo receipt redirect, persisted design choices, curated presets, estimate forwarding, blocked-browser-storage fallback and genuine PDF Blob generation. No live mail/webhook credentials were used and no external enquiry delivery was claimed.
- Normal and maximum seven-add-on PDF layouts visually inspected: one A4 page, readable INR amounts, no overlap.
- The initial Next.js homepage bundle report is approximately 115 KB first-load JS; optional motion/WebGL modules are deferred. This build-report figure is not a real-device performance certificate.
- OpenGraph generator produces 1200×630 images. Preview robots.txt disallows crawling; real content/domain approval is required before indexing.
- Production dependency audit reports no known advisories after locked framework/transitive patch updates.
- All 20 bundled image/font/video/PDF assets were reconstructed from checksummed source bundles into a clean directory with matching SHA-256 digests.

## Visual review

Five parallel workstreams contributed design, engineering, motion, conversion and security review. All seed template captures were individually reviewed across desktop and mobile; detailed snapshot reports accompany the code. Old full-page screenshots placed fixed mobile controls at the first viewport's edge, creating apparent mid-image text collisions. Final controls are discreet icons, sound is hidden on mobile, legal pages and the CMS editor omit marketing overlays, and scroll insets reserve focus/anchor breathing room. A persistent mobile enquiry bar is intentional on marketing pages; content remains reachable by ordinary scrolling. No testimonial, rating, completed-project count or founder portrait was invented.

## Deliberate departures from the initial brief

- Hero photograph is the eager LCP asset; the supplied reference film is opt-in rather than an automatically downloaded full-screen loop.
- Reference-site ideas were reimplemented originally, not copied from an unlicensed clone. The verified Oryzo MIT repository contains coaster models, not the website source.
- No fake Google rating, testimonial carousel, press logos or invented project evidence.
- No interruptive exit-intent email gate. The useful design brief checklist is directly downloadable.
- Multipart references are capped at 4 MB combined so the supplied Vercel deployment path fits the platform's 4.5 MB request limit. The requested 10 MB upper limit requires a direct-to-private-storage uploader; this build does not pretend to provide it.

## Not yet verified / business launch prerequisites

Approved real project photography/facts and founder details; real address/phone/email/social profiles; legal review; live Sanity publication; authenticated Resend/Sheets/Turnstile delivery; private file retention and scanning policy; shared WAF/rate limiting; domain and Vercel deployment.

The requested Moto-G4-class Slow-4G LCP <1.8s, INP <150ms, CLS <0.05 and real transferred-page-weight budgets have **not** been certified. Remote browser proxy timing is not a valid substitute for those device/network measurements. No traffic, ranking or conversion uplift multiplier is claimed.
