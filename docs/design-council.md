## Original visual synthesis
- **First viewport:** small MK wordmark; Work / Studio / Approach / Contact; compact consultation link. One rich, believable interior composition with negative space. Overline “Interior architecture · Mumbai.” A 2-line serif statement, then a precise sans sentence. Two visible actions: **Explore the studies/work** and **Discuss your space**. Avoid a crowded row of badges.
- **Composition:** hero 65–80% image weight; then a generous paper pause; work in asymmetrical editorial pairs (one broad room + one close material/detail); philosophy in a narrower text column; dark process passage; paper enquiry ending. Vary scale, not card styles. Hairlines and squared images, little or no rounding, no SaaS dashboard grids.
- **Tokens from brief:** paper `#F5F2EB`, ink `#282923`, terracotta `#A55D48`, brass `#A88753`; Instrument Serif display + DM Sans body. Brass is decorative, not small text on paper without contrast verification. Use 16–18px body, 14px floor for metadata. At 390px use 20px gutters, comfortable 44px controls and no horizontal document overflow.
- **Imagery:** consistent warm daylight, honest stone/wood tones, wide architectural lens without distortion, human-scale objects, one macro detail. Supplied client photography is preferred. Concept imagery must be labelled; stock/generation is not proof of authorship. Do not use unrealistically opulent rooms as promises of MK’s work.
- **Copy:** architectural specificity over luxury adjectives. “A clear brief. Carefully chosen materials. One accountable team.” Avoid “bespoke excellence,” “world-class,” “timeless elegance” and unsupported guarantees. The enquiry is for an actual conversation, not a theatrical dead end.

## Five purposeful interaction treatments

1. **Light study — atmosphere, not distortion.** An explicit Day / Evening control crossfades two matched room studies; small caption explains lighting intent. Optional pointer-based grazing-light mask touches only a material detail, not text or full-room geometry. Static hero loads first. With reduced motion switch instantly; touch uses the same labelled buttons. If two valid matched images are absent, use a truthful material-light study rather than fake before/after.
2. **Editorial project lens — inspect intent.** Work filters by verified typology or, for concepts, design direction; state is visible and shareable. Cards have always-readable captions, a subtle 1.02 image scale on hover/focus, and open a keyboard-operable image/dialog study. Click hotspots reveal actual design observations; never invented dimensions or construction facts. This turns browsing into informed shortlisting.
3. **Material composer — articulate preference.** Select wood / stone / textile palettes and see a curated collage and readable selection summary change together. Three or four choices, not a simulation engine. Carry the chosen palette into the enquiry. Label as an exploratory design preference, not a priced/specifiable construction promise. Keyboard buttons plus status announcement; use bounded opacity/layout transitions.
4. **Sketch-to-space / process reveal — explain accountability.** A five-stage line has explicit selectable stages: Brief, Concept, Detail, Execute, Handover. Each exposes what the client decides and what the studio delivers. On desktop a single connector draws; mobile is a vertical accordion. Only show authentic plans as real project evidence; conceptual schematics are clearly illustrative. The page remains readable without animation.
5. **Investment-to-conversation — qualify without misleading.** Estimator uses selectable property type, area and finish level; instant range and assumptions; “Discuss this brief” carries choices into contact. Values in Doc 10 are **demo planning assumptions, not approved MK rates**. Mark estimates non-binding and dependent on site/scope. Contact form preserves selections, validates inline and only confirms receipt after a real delivery success. Without a verified phone, do not invent a WhatsApp number; keep a working enquiry/demo path with honest state.

**Polish is subordinate:** contextual native cursor/hover labels, fine nav underline and subtle image reveal may support these five. No cursor replacement, exit-intent interruptions, autoplay audio, loading ritual, obligatory smooth-scroll or concurrent bouncing CTAs. If sound is retained, explicit opt-in with persistent mute; it is not a signature priority.

## Performance and accessibility vetoes
- **Brief budget conflict:** page weight ≤1.5MB and hero film ≤2MB are not simultaneously safe if both count in initial transfer. Prefer optimized still poster (rough target 150–300KB at desktop) and delay video until after meaningful content, or load only by explicit choice. Do not preload poster plus multiple video encodings.
- **One animation owner per element.** GSAP, Lenis, Framer and WebGL together can inflate initial JS and fight over transforms. Use CSS for basic hover/reveal; dynamic-load the material module. Keep optional canvases out of the initial route. Hardware concurrency is not a dependable GPU capability verdict.
- **No perpetual render tax:** cap device pixel ratio, limit texture resolution, suspend canvas/video offscreen and when tab hidden, clean listeners/timelines on unmount. Avoid full-screen blur, animated grain filters, large liquid shaders and long pinned scroll scenes.
- **LCP/content cannot wait for a preloader or scroll trigger.** Server/static HTML contains the headline, image, links and core copy. Set image dimensions/aspect ratios to prevent CLS; reserve module space rather than a shifting null placeholder. Only LCP media eager; remaining images responsive and lazy.
- **Native scrolling by default.** No horizontal scroll hijack. Reduced motion removes parallax, rotation, cursor lag and scrubbed pinning, not merely switching everything to a fade. Preserve browser find, anchors, focus and back navigation.
- **Verify instead of claiming:** actual mobile throttled tests, keyboard traversal, focus return from menus/lightboxes, contrast on image overlays, form error/success states, no-JS core access. A beautiful desktop screenshot is not mobile/CWV evidence.

## Council gate before handoff
1. At a glance: interior practice + Mumbai + clear next step, without fake proof.
2. At desktop and 390px: no overlaps; restrained strong typography; image crops intentional; no giant dead zones.
3. Every visible control either works or is plainly labelled demo/unavailable; no false “sent” confirmation.
4. Five interactions add understanding and choice; no more than one active spectacle per viewport.
5. All concepts/media/estimate assumptions visibly distinguished from completed client work and commitments.

**Implementation priority:** first finish hero, editorial work sequence and contact. Then material composer + estimator + process. The signature is considered space, not the number of animation packages.
